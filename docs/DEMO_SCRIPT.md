# PermitPulse — 2:30 Demo Script

## 0:00–0:20 — Problem
“Permit teams waste hours calling offices for basic status updates. PermitPulse turns that phone chase into one structured AI call.”

Show the PermitPulse landing page and one synthetic permit case.

## 0:20–0:45 — Preflight
Show the permit number, jurisdiction, project address, and phone field. Point out the three live-call gates: contact permission, AI disclosure approval, and fresh call intent.

Mention that hackathon field trials route only to an explicitly consenting test number.

## 0:45–1:15 — CALL-E execution
Trigger the real CALL-E call. Show that PermitPulse sends a bounded task: identify as AI, ask only about the permit, and never make commitments or government claims.

Show the returned CALL-E call ID/status.

## 1:15–1:50 — Structured result
After completion, show the result card:
- permit status
- missing items
- inspection readiness
- next available date if provided
- department/contact
- next safe action

Emphasize that unknown information stays unknown rather than being guessed.

## 1:50–2:15 — Why it matters
“Instead of a project manager spending 20 minutes on hold and then manually writing notes, PermitPulse returns an operational next-step card that can feed the project workflow.”

Briefly show the reusable `permit-status-check` skill and mention the official repository validator passes.

## 2:15–2:30 — Close
“PermitPulse gives contractors something they actually need: fewer status-chasing calls, fewer missed corrections, and a faster path from permit uncertainty to the next human-owned action.”

End on the product name and functional demo URL.
